# Antigravity 账号切换器：产品设计

状态：设计草案｜2026-11-10｜平台：macOS

## 定位与目标

一个常驻菜单栏的小工具，帮助用户管理自己的多个 Antigravity 账号（例如工作账号和个人账号）：添加账号并完成登录、方便地切换账号，以及删除不再需要的账号，同时尽可能保留同一台机器上的工作环境。这里的“创建账号”指将新账号添加到本工具并完成 Google 原生登录；Google 账号注册本身由 Google 完成。工具不收集密码。

核心承诺是只改变经过验证的登录状态，不主动替换工作区、项目文件、设置、扩展、历史记录或设备标识。云端内容、账号权限、同步结果及 Antigravity 自身随登录发生的变化不受本工具控制；不能在未经验证前承诺所有信息绝对不变。

## 用户与范围

面向在同一 Mac 上使用工作与个人账号的 Antigravity 用户。首版只支持本机、单个 macOS 用户和经测试的 Antigravity 版本；不做跨设备同步、自动轮换、配额查询、代理、CLI、多平台或设备标识修改。账号数量不设人为上限，但以少量账号的易用性为优先。

## 菜单与状态

菜单栏图标打开面板：顶部显示当前账号及状态；下方列出已保存账号（名称、脱敏邮箱、当前标记、需要重新登录标记），点击非当前账号切换。底部提供“添加账号”“管理账号”“设置”和“退出”。管理页支持重命名显示名称、移除保存的账号；删除账号需二次确认，并说明只删除本工具保存的账号记录和凭据副本，不删除 Google 账号或云端数据，也不撤销授权。删除当前账号时，IDE 保持当前登录；菜单显示“当前账号未保存”，用户可重新添加。首次使用显示发现 IDE 和保存当前账号的引导。不可识别当前账号时显示“当前账号未知”，不能猜测。

## 关键流程

### 添加并登录新账号

1. 用户点击“添加账号”；说明需要正常退出并重启 Antigravity，提示保存工作，展示取消选项。检测不到受支持的安装或存储结构时停止并说明原因。
2. 用户确认后，应用捕获并安全保存当前登录状态和恢复点，验证可读；无法保存则停止。请求 IDE 正常退出，若用户取消退出、进程未退出或超时，取消操作，不强制结束。
3. 清除**已验证的登录字段**并启动 IDE 到原生登录界面；用户在 Google/Antigravity 界面登录，也可以在那里注册 Google 账号。工具不嵌入登录页、不索取密码。
4. 返回工具点击“完成登录”，检测 IDE 实际登录结果及稳定账号标识。登录尚未完成时可重试或取消；取消、超时或失败提供恢复原账号。为读取一致状态需要再次请求正常退出 IDE，用户可取消。
5. 安全保存新凭据并去重：同一稳定账号标识更新已有记录，不创建重复项；身份无法确认则不保存、不声称成功。保存成功后新账号保持当前，重新启动 IDE 并验证；原账号仍可切回。

### 切换已有账号

选择目标 → 展示目标和重启提示 → 用户保存并确认 → 正常退出 IDE → 保存当前最新凭据和恢复点 → 替换最小登录状态 → 重启 → 验证目标身份。成功后更新当前标记；验证失败显示“未确认”，提供恢复原账号及诊断信息。取消退出时不修改数据。切换期间禁用并发操作。

### 删除账号

在管理页选择账号并确认删除。删除后它不再出现在可切换列表，本工具删除对应凭据副本和与该账号关联的恢复材料；删除失败时保留记录并提示重试。删除非当前账号不影响当前 IDE 会话。删除当前账号不会让 IDE 退出登录；若稍后希望再次切换到它，需重新添加并登录。删除操作不影响其他已保存账号。

### 异常与恢复

凭据过期或撤销时提示通过添加/重新登录流程更新，不承诺离线可用；钥匙串锁定或权限拒绝时保留原状态并引导解锁；磁盘空间不足、数据库锁定、版本不支持或备份失败均停止写入。异常退出后下次启动先检查未完成操作，提供恢复，不自动覆盖可能已变化的数据。恢复失败时保留恢复材料并提供明确的手动恢复指引；日志不得包含凭据。

## 验收标准

- 从已登录 A 出发，添加并登录 B；A、B 均显示正确且无重复，B 当前可用；依次切回 A、B，IDE 实际身份与界面一致。
- 取消登录、重复登录、用户拒绝退出、过期凭据和钥匙串拒绝均有可理解的状态和恢复路径。
- 使用代表性的项目、未保存编辑、设置、扩展、工作区及历史记录做切换前后检查；未保存编辑由 IDE 退出确认保护。验证发现变化时不得宣称该版本支持。
- 任意写入失败或进程中断后，恢复流程可回到切换前状态；不记录或展示 token。
- 删除非当前账号和当前账号后，列表与实际 IDE 登录状态符合上述规则；其他账号仍可正常切换，删除失败可重试。
- 明确显示支持的 IDE/macOS 版本，未知版本默认只读。
