# 技术方案：Antigravity 账号切换器

状态：待可行性验证｜2026-11-10。配套 [产品设计](product-design.md)。

## 决策与前置验证

建议 macOS 原生 Swift/SwiftUI + AppKit（菜单栏与进程生命周期），Security.framework 管理本工具的凭据，SQLite 系统库按需访问 IDE 数据。选择原生栈是为了菜单栏、钥匙串和进程管理；最低 macOS 版本、沙盒可行性及分发方式在验证后确定。初版不依赖网络服务，也不主动调用配额或认证 API。

最高风险是 Antigravity 的认证状态属于内部实现，可能位于数据库、钥匙串或两者，且版本会变化。参考项目的不同说法不能证明当前版本可用。先在隔离测试用户和测试账号中记录 IDE 精确版本、构建号、安装路径及 macOS 版本，对比 A 登录、退出、B 登录状态，确认认证字段、稳定身份来源、依赖关系、刷新行为与正常重启要求。验证 SQLite WAL、共享钥匙串访问权限及退出后后台进程；严禁将真实 token 放入测试夹具。不能证明最小写入安全时只提供只读检测，不发布切换功能。

## 组件与数据

- UI：菜单、向导、状态和恢复提示；只持有账号元数据，不显示凭据。
- AccountStore：随机生成本地 ID，保存显示名、脱敏邮箱、稳定身份标识、凭据引用、更新时间与健康状态；敏感认证材料放入本应用的 Keychain 条目，使用仅本机可用的访问属性，处理系统授权拒绝。元数据不包含 token。
- IDEAdapter：按已验证版本识别安装、进程、存储布局和身份；以版本白名单选择实现。不同布局独立适配，未知版本拒绝写入。路径、表名和键名由实测固定，不根据模糊匹配覆盖。
- SwitchCoordinator：串行执行操作、持久化阶段、创建恢复点、验证和恢复。以进程级锁及磁盘锁阻止重复实例；每次写入前再次确认 IDE 已完全退出及源数据未变化。
- RecoveryStore：保存加密的最小认证状态和操作日志，密钥由 Keychain 保护，目录仅当前用户可读；设置短期保留和清理策略。不得把数据库整库恢复作为常规切换方案。

## 操作协议

状态：`idle → preparing → awaitingQuit → backedUp → applying → launching → verifying → committed`；任意阶段可进入 `recoveryRequired`。操作记录仅含随机操作 ID、版本、阶段、时间、目标引用及非敏感错误码；阶段变更落盘。备份加密后先验证可解密和完整性再进入写入阶段。

1. 预检：支持版本、目标凭据可读、磁盘空间、路径及进程；获得用户确认后请求正常退出，等待所有相关进程退出。取消或超时停止，不强杀。
2. 在静止状态重新读取当前凭据，保存最新值；创建最小恢复点。验证待写入数据的格式和账号身份；比较预检时指纹，发现外部变更停止。
3. 使用版本适配器只写经过验证的认证字段。若数据库承载字段，使用 SQLite 事务与参数化语句，处理 WAL 和锁；若钥匙串与数据库均需更新，不能假设跨存储原子性，逐步记录并准备补偿。绝不覆盖整个用户数据目录或无关字段。
4. 启动 IDE，基于可验证的身份来源确认目标；仅在确认后标记成功。启动失败、身份不符或无法验证时保留恢复点并显示未确认。恢复前再次正常关闭 IDE、检查外部变化；有冲突时停止自动恢复，提供手动指引。
5. 提交后保留最近一次恢复点直至下一次成功操作或明确清理；不保存明文临时文件。崩溃后按日志和实际状态核对，不能盲目重放。

添加账号复用该协议：保存 A 的恢复点后，清除已验证的认证字段并启动原生登录；登录完成并正常退出后读取、确认和保存 B，去重后重新启动验证。登录期间任何取消都可请求恢复 A；用户继续使用 IDE 造成状态变化时先检测冲突。若清除认证字段无法可靠触发原生登录，添加功能保持不可用，不能要求用户提供密码或复制 token。

## 安全与隐私

凭据、恢复材料及 Keychain 访问视为高敏感数据；不输出到日志、崩溃报告、命令参数、剪贴板或遥测。日志只记录阶段和脱敏错误码；不上传数据。操作系统钥匙串授权由用户控制，不绕过权限或要求管理员权限。删除账号时先记录删除意图，再删除本工具 Keychain 副本及相关恢复材料，最后删除元数据；失败时保留可重试状态，不声称删除完成。删除当前账号不改写 IDE 当前会话，界面显示当前账号未保存；不撤销 Google 授权，也不删除 Google 账号或云端数据。删除与切换操作串行，避免删除正在使用的恢复点。发行前评估签名、公证、自动更新及许可证；不声称官方支持。

## 验证计划与发布门槛

1. **探针**：在隔离环境对比 A/B、登录、退出、刷新及 IDE 升级前后状态，确定最小字段和身份验证手段；记录具体版本、证据与未解决问题。
2. **单元与故障注入**：状态机每个阶段模拟进程中断、Keychain 拒绝、SQLite busy、空间不足、重复身份、凭据损坏及外部修改；确认失败不误报成功，恢复冲突不覆盖新数据。
3. **端到端**：真实测试账号 A/B 添加、重复登录、切换、撤销授权和恢复；验证工作区、设置、扩展、项目文件、历史记录及 IDE 退出提示。包含 IDE 未运行、多个窗口及后台进程。
4. **兼容性**：在声明支持的每个 macOS/IDE 版本组合验证，升级后默认只读直到通过；检查钥匙串锁定、不同安装路径和重启。测试结果与构建号随发布记录。
5. **安全检查**：检查日志、备份、崩溃产物和文件权限无明文凭据；人工验证恢复与删除。

任一关键状态无法可靠识别、原生登录无法触发、失败无法恢复或非认证数据发生不可解释的变化，均阻止发布写入功能。“所有其他信息不变”是验证目标，不是对第三方云端状态的保证。

## 实施顺序

先完成存储与身份探针并形成版本兼容记录；再实现只读发现和菜单；随后实现恢复与切换事务，最后实现添加账号向导、故障注入和真实账号验收。探针决定适配器细节，不预先假定数据库键或钥匙串条目。
